Score = the game's official reward: +1000/N for each of the N road tiles touched, −0.1 per frame, −100 for leaving the map. 20 seconds per race. The game only ends a race early when every tile has been touched, so most races run the full 20 s.

      The fine print

      • Three training runs per AI. The tests compare these six drivers on 100 tracks; they can't say how much a fresh training run would vary.
      • "Unseen colors" means new schemes from the same random formula B practised with. Other changes (lighting, textures, a different formula) weren't tested.
      • Robust, not immune. B still scores less on unseen colors than on normal ones.
      • Not solved. No AI averages the official 900. Most races hit the 20-second limit because the game only ends a race early once every single road tile is touched.
